隐私政策

更新日期：2026 年 10 月 19 日

App 内的数据

当前 Android 版本无需注册，不启用在线账号、广告或行为分析服务。昵称、收藏、笔记、制作记录、搜索历史、酒柜及自定义预设保存在本机。配方、图片和音频随 App 提供，主要功能可离线使用。

保存、备份与删除

你可以在 App「数据管理」中导出、恢复或清空记录。卸载或清除系统应用数据会删除应用私有数据。导出的备份由你自行保管；选择云盘等文件提供程序时，文件会交由该服务处理。

网站与下载

本网站使用 GitHub Pages 托管，安装包通过 GitHub Releases 分发。本站不嵌入第三方广告或行为分析脚本。网站访问、安装包下载会由托管服务处理，请参阅 GitHub 隐私声明。

主动分享与反馈

邮件反馈、系统分享以及备份仅在你主动操作时进行，相关外部服务按其自身政策处理所提交的数据。App 默认不附加设备信息，可由你自行选择是否提供。
